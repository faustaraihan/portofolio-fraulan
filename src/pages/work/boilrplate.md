<section id="focus" class="case-chapter boil-focus"><div class="case-reading-wrap">
<p class="case-eyebrow">Design priorities</p>
<div class="boil-focus-layout"><div><h2>Keep the first version<br />focused on one builder.</h2><p>Make personal reuse useful before adding team workflows or more automation.</p></div><ul class="boil-priorities"><li><h3>Save the thinking</h3><p>Tools, rules and a short reason for each choice.</p></li><li><h3>Make it easy to reuse</h3><p>Start from a saved setup instead of piecing together old notes.</p></li><li><h3>Keep changes under control</h3><p>Let each project keep the setup it started with.</p></li></ul></div>
<p class="boil-deferred">Not in the first version: team workspaces, a marketplace, or automatic repository creation.</p>
</div></section>
