# DESIGN — Fraulan / Motion edition 2.0

User-approved direction from latest request supersedes all old visual/motion restrictions: clean composition with complex coordinated animation, black/white interface typography, expressive fonts, independently colored objects. This is a personal developer portfolio, not an agency.

## Composition
White canvas (#fafafa), black type (#111111), black/white controls. Syne variable for display lettering, DM Sans for readable text, self-hosted Latin WOFF2 with OFL. Large asymmetrical two-line identity on a spacious stage. An original six-part capsule sculpture evokes assembly and software building; no Ribbit assets, mascot, logo or copied transition. Remove stickers, fake browser chrome, offset borders, ticker strip and colored typography.

Home retains four projects in the locked order Codestroke, Boilrplate, Karisma AI, Moomori, plus all factual bio/experience. Desktop Work uses a compact split media/copy composition so each item reads in one viewport; the direction alternates by project, and mobile stacks the same content. Each work item uses its own media ratio and alignment, with no generic colored frame behind the supplied visuals. Codestroke, Boilrplate, and Karisma AI open local case studies; Moomori remains a preview. About and contact use spacious typography. Case studies inherit the same fonts and monochrome text.

## Motion
Supplied project logos sit behind the trailing end of Work and case-study titles, slightly offset to the right. Text stays above subdued logos with a fine canvas-colored edge for readability. Boilrplate sits behind the final e; Codestroke retains its lime mark and Karisma its wide identity. Hover gently settles the angle. Karisma's SVG embeds its original raster logo without a local filesystem dependency.
Work copy is one readable vertical column beside each visual, never a nested title/summary split. Desktop media is capped by viewport height. Original orbit, asterisk and loop ornaments connect sections; scroll rotates them and project copy enters in a short stagger. All decoration is hidden from assistive technology and stops with the existing motion control.
Native Web Animations load choreography; scroll-linked sculpture rotation/separation and opposing headline movement; project image rotation and reveal settle as each scene enters viewport. One event-scheduled requestAnimationFrame updates motion, not an endless idle loop. Native scroll is never intercepted. A visible Motion on/off control allows pausing decorative motion. prefers-reduced-motion reacts at runtime; no-JS and blocked scripts leave readable content and navigation. Mobile reduces travel and disables pointer effects. Browser navigation transitions use progressive CSS view transitions only if supported.

## Validation

A small two-color orbit marks the transition to numbered article chapters. Cover settling, chapter reveals and a next-project link add motion and continuity, with a local motion toggle and reduced-motion support.
